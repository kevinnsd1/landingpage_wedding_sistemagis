# Landing Page Undangan Digital Wedding - Sistemagis

Platform Landing Page & Perencana Undangan Digital Pernikahan modern, minimalis, dan responsif yang dibangun menggunakan React, TypeScript, Vite, TailwindCSS, dan React Router.

## 🚀 Fitur Utama
- **Hero Slider & Carousel**: Tampilan antarmuka *luxury blush* minimalis dengan navigasi interaktif.
- **Katalog Templat Undangan**: Pilihan templat desain pernikahan dengan layout *zig-zag showcase*.
- **Halaman Fitur Lengkap (`/fitur`)**: Penjelasan fitur RSVP realtime, Amplop Digital/QRIS, Galeri Foto & Video, Peta Google Maps/Waze, dan Musik Custom.
- **Aplikasi Wedding Budget & Savings Planner (`/wedding-planner`)**:
  - Target Total Budget & Sisa Margin Realtime.
  - Form pencatatan tabungan pasangan (CPW & CPP).
  - Manajemen rincian pengeluaran vendor & status pembayaran interaktif (`Lunas`, `Sudah DP`, `Belum`).
  - Checklist Timeline Persiapan H-12 Bulan s/d Hari-H.

## 🛠️ Teknologi yang Digunakan
- **Frontend Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Routing**: React Router v7
- **Iconography**: Lucide React Icons

## 💻 Cara Menjalankan Aplikasi

1. Clone repositori:
```bash
git clone https://github.com/kevinnsd1/landingpage_wedding_sistemagis.git
cd landingpage_wedding_sistemagis
```

2. Install dependensi:
```bash
npm install
```

3. Jalankan server pengembangan lokal:
```bash
npm run dev
```

4. Build untuk produksi:
```bash
npm run build
```
